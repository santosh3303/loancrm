# Running the frontend (the app you actually use)

1. Make sure the backend is already running (see backend/README.md) - start it FIRST.
2. Open a separate terminal in this `frontend` folder.
3. Run: npm install   (first time only)
4. Run: npm run dev
5. It will show a link like http://localhost:5173 - open that in your browser.
6. Leave this terminal window open while you use the app.
